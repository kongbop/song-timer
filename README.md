# 노래 알람 타이머

타이머가 끝나거나 정한 시각이 되면, 넣어 둔 유튜브 노래가 페이지 안에서 바로 재생되는 웹 타이머예요.

## 기능
- **타이머**: 1분·3분·5분·10분·25분·1시간 빠른 선택, 또는 시·분·초 직접 입력
- **알람 여러 개**: 시각마다 알람을 추가하고, 켜기·끄기·수정·삭제 가능 (지난 시각이면 다음 날로 자동 설정)
- **알람마다 다른 노래**: 알람별로 유튜브 링크와 시작 위치를 따로 지정
- **타이머와 알람 동시 사용**: 알람을 켜 둔 채로 타이머를 돌릴 수 있음
- **볼륨 조절과 미리 듣기**: 타이머 노래와 각 알람 노래를 정한 볼륨으로 미리 들어 보기
- **예비 알람음**: 자동 재생이 막히거나 재생할 수 없는 영상이면 알람음이 대신 울림

## 주의
- 타이머나 알람이 켜져 있는 동안 탭을 닫거나 컴퓨터를 절전 모드로 두면 울리지 않아요.
- 알람은 한 번 울리면 꺼져요. 다시 켜면 다음 그 시각에 울려요.
- 페이지를 새로 열었을 때는 화면을 한 번 눌러야 브라우저가 소리 재생을 허용해요.
- 아이폰·아이패드에서는 볼륨 막대 대신 기기 볼륨 버튼으로 조절해야 해요.
- 일부 영상은 업로더가 다른 사이트에서의 재생을 막아 두어 재생되지 않아요. 같은 노래의 다른 영상을 써 주세요.
